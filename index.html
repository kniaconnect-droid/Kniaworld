Cara Deploy File HTML

Pilih salah satu platform di bawah — semua gratis & tanpa perlu coding!

✅ Paling mudah — drag & drop langsung!

Cocok untuk pemula, tidak perlu akun GitHub.

1

Daftar / Login ke Netlify

Buka app.netlify.com → Sign up gratis pakai email atau Google.

2

Download file HTML dari Claude

Di Claude Artifacts → klik tombol Download → simpan file .html ke komputer kamu.

3

Buka Tab "Sites" → Deploy Manually

Di dashboard Netlify, scroll ke bawah → ada kotak "Want to deploy a new site without connecting to Git?"

4

Drag & Drop file HTML

Seret file .html ke kotak drop zone → Netlify langsung upload otomatis.

5

Dapat Link Publik! 🎉

Selesai! Netlify kasih link seperti namamu.netlify.app — siap dibagikan atau dijual!

⚡ Cepat & profesional

Butuh akun GitHub, tapi link lebih clean dan bisa custom domain.

1

Daftar / Login ke Vercel

Buka vercel.com → Sign up pakai akun GitHub (gratis).

2

Upload file ke GitHub dulu

Buka github.com → New Repository → Upload file HTML → Commit.

3

Import Repository di Vercel

Di dashboard Vercel → klik Add New → Project → pilih repo GitHub tadi → klik Import.

4

Klik Deploy

Biarkan semua setting default → klik tombol Deploy → tunggu beberapa detik.

5

Dapat Link Publik! 🎉

Vercel kasih link namamu.vercel.app — siap dibagikan atau dijual!

🔶 Performa terbaik & CDN global

Direct upload tanpa GitHub, cocok juga untuk produk yang butuh loading super cepat.

1

Daftar / Login ke Cloudflare

Buka dash.cloudflare.com → Sign up gratis pakai email.

2

Buka menu Workers & Pages

Di sidebar kiri → klik Workers & Pages → klik tombol Create.

3

Pilih tab "Pages" → Upload Assets

Pilih tab Pages → klik Upload Assets → beri nama project kamu.

4

Upload file HTML

Klik Select from computer → pilih file .html → klik Deploy site.

5

Dapat Link Publik! 🎉

Link seperti namamu.pages.dev langsung aktif — siap dibagikan atau dijual!

✏️ Revisi: Ganti / Tambah Soal
Pilih ini kalau game kamu sudah pernah dibuat sebelumnya dan sekarang cuma mau ganti isi soal, nambah soal baru, ubah tingkat kesulitan, atau terjemahkan ke bahasa lain — tanpa bikin ulang dari nol.

📎 Yang perlu disiapkan: lampirkan file kode HTML game yang sudah kamu generate sebelumnya (drag & drop langsung ke chat Claude/Gemini bareng prompt ini). Kalau soal barunya dari worksheet atau buku, tulis ringkasannya di kolom "Materi / Topik Soal Baru" di bawah.

🚀 Revisi: Upgrade Fitur & Level
Pilih ini untuk nambahin fitur baru ke game yang sudah jadi — misalnya level baru, leaderboard, sistem nyawa, timer, sertifikat, atau audio.

📎 Yang perlu disiapkan: lampirkan file kode HTML game yang sudah digenerate sebelumnya. Jelaskan sedetail mungkin fitur yang kamu mau di kolom "Detail / Spesifikasi Fitur Baru" supaya hasilnya sesuai ekspektasi.

🔧 Revisi: Perbaiki Bug & Tampilan
Pilih ini kalau ada bug (tombol nggak jalan, skor salah hitung, game macet) atau kamu mau ubah tampilan/warna/font dari game yang sudah ada.

📎 Yang perlu disiapkan: lampirkan file kode HTML game yang bermasalah. Kalau ada, sertakan juga screenshot masalahnya (opsional, tapi sangat membantu AI paham konteksnya).

Pilih ini untuk bikin 1 file game baru yang isinya 5 paket materi berbeda dalam 1 menu pilihan — cocok dijual sebagai paket bernilai lebih tinggi.

📎 Yang perlu disiapkan: ini untuk BUAT BARU, jadi kamu nggak perlu lampirkan kode lama. Cukup isi 5 materi di kolom di bawah. Kalau salah satu materi berasal dari worksheet yang sudah ada, lampirkan juga file worksheet-nya supaya kontennya presisi.

📄 Ubah Worksheet jadi Game
Pilih ini untuk mengubah worksheet, lembar soal, atau materi ajar yang sudah kamu punya menjadi game interaktif siap jual.

📎 WAJIB lampirkan file worksheet-nya (PDF, Word, atau foto/scan) di chat Claude/Gemini bareng prompt ini, supaya AI membaca isi soalnya persis seperti aslinya. Kalau filenya nggak ada, minimal ringkas isi soalnya selengkap mungkin di kolom "Ringkasan Isi Worksheet / Materi".

🖼️ Tambah / Ganti Gambar Sendiri

📎 WAJIB lampirkan 2 hal ke chat Claude/Gemini: (1) file kode HTML game yang sudah digenerate, dan (2) contoh gambar yang mau dipakai (boleh beberapa sekaligus). Kasih nama file yang jelas — misalnya maskot.png, ikon-benar.png, background.jpg — supaya AI tahu gambar mana untuk elemen yang mana.
